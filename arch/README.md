# ARCH node files

These are the ARCH node files, staged here under AngelSkies TV before ARCH becomes its own AR/VR (Meta Quest) / Google Play app.

- `ARCH.html` — the ARCH Station page from the Dropbox "GitHub" folder (unchanged).
- `media/` — reserved for ARCH media. The Dropbox "Arch Angel" folder currently contains only Windows shortcut files (`.lnk` for DAZ Install Manager, DAZ Studio 4.21 and itch), which are not media and were not copied.

Note: `ARCH.html` references `../style.css`, `../script.js` and `../config/arch_data.json` from the web dashboard; those paths will need adjusting when ARCH moves into its own app.
